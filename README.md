# Training Center Management

An Odoo 19 custom module for managing training courses and integrating them with the Sales module.

## Overview

The Training Center module helps organize training courses and connect course registration with Odoo sales orders. It extends standard Odoo functionality to support the specific needs of a training center.

## Features

- **Course Management** — Create and manage training courses and their details
- **Instructor Management** — Link instructors to training courses
- **Sales Integration** — Connect training courses with products and sales orders
- **Seat Management** — Define course capacity and track registered and remaining seats
- **Automatic Updates** — Update registered seats when a sales order is confirmed

## Technologies

- Odoo 19
- Python
- XML
- PostgreSQL

## Dependencies

- `base`
- `sale`

## Installation

1. Clone or download this repository into your Odoo custom addons directory
2. Make sure the required dependencies are installed
3. Restart the Odoo service
4. Activate Developer Mode
5. Update the Apps List
6. Search for **Training Center Management** and install the module

## Purpose

This project was developed to practice Odoo module development, model relationships, computed fields, sales integration, and business workflow customization.
